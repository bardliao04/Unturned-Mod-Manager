# Unturned 模組管理器 v1.1

安裝、更新與移除相容的 Unturned 漢化及 mod，支援玩家遊戲與本機可存取的 Windows 專用伺服器。

本工具使用 **OpenAI GPT AI** 協助開發與撰寫說明。

## 下載與開始使用

[下載最新正式版](https://github.com/bardliao04/Unturned-Mod-Manager/releases/latest)

在 Assets 下載 **Unturned-Mod-Manager_v1.1.zip**，完整解壓縮後開啟 **Unturned模組管理器.exe**。保留同名 .exe.config 與使用說明。GitHub 的 Source code 下載不包含管理器程式。

1. 選擇玩家遊戲或 Unturned 伺服器，確認目標資料夾。
2. 等待 Steam 下載完成，按重新掃描；使用分享安裝包時，選擇匯入 ZIP。
3. 確認來源、版本與勾選項目，關閉遊戲或伺服器，再按安裝／更新。
4. 安裝後依模組自己的說明操作。漢化啟動選項為 -Lang=Tchinese，需由玩家自行設定。

訂閱是下載來源；Steam 更新後仍須重新掃描並安裝，才會更新遊戲中的檔案。

## v1.1 更新

- 工作坊、管理器與分享 ZIP 統一採兩段式公開版號，例如 v1.1、v1.3；內部建置編號仍用於更新排序與降版判斷。
- 已安裝紀錄保留公開版本，即使來源暫時消失仍可辨識。
- 支援現有 Data 漢化包與含 unturned-manager.json 的模組，不需重複的管理器專用資源。
- 安裝成功或失敗後清理本次寫入暫存；保留原始還原備份。
- 玩家程式不包含開發測試執行器，發布包只含必要檔案。

## 版本、安裝與還原

管理器列出本機已有的版本，不下載工作坊歷史版本。切換較舊或無法比較的版本仍會要求確認。同版本重裝會重新覆蓋清單內的全部檔案；更新會移除舊管理清單中已退役的檔案，不清空其他模組或存檔。

安裝前驗證來源並備份，失敗時回滾。移除或還原遇到後續修改時仍會檢查並提示。

設定、匯入包、安裝紀錄及備份位於：
%LOCALAPPDATA%\UnturnedModManager

請保留此資料夾，以便還原。移除 ZIP 匯入來源不等於解除安裝 mod。

## 使用條件

Windows 10／11、.NET Framework 4.8。管理器不附 mod 資源、不啟動遊戲、不執行安裝包中的 EXE 或腳本。
伺服器目標只接受宣告伺服器角色的模組；功能操作本機可存取的檔案，不提供遠端上傳或伺服器啟停。

各 mod 的遊戲模式與相容性依作者說明確認。公開版本一致不代表所有地圖、任務或多人環境均已完成實機驗證。

## 管理器更新

每次開啟時檢查本專案 GitHub 正式發行版；網路失敗仍可使用本機功能。管理器更新時更換程式與 config，保留原有安裝紀錄與備份。
