# Unturned 模組管理器

協助安裝、更新與移除相容的 Unturned 漢化及 mod，支援玩家遊戲與本機可存取的 Windows 專用伺服器。

本工具使用 **OpenAI GPT AI** 協助開發與撰寫說明。

## 下載

[下載最新正式版](https://github.com/bardliao04/Unturned-Mod-Manager/releases/latest)

在 Assets 下載管理器 ZIP，完整解壓縮後開啟 **Unturned模組管理器.exe**。請下載程式安裝包，GitHub 的 Source code 下載不包含管理器程式。

## 使用方式

1. 選擇「玩家遊戲」或「Unturned 伺服器」，確認目標資料夾。
2. 按「重新掃描」讀取已下載的工作坊內容，或「匯入 ZIP」加入相容安裝包。
3. 在「可用版本」選擇版本與來源，勾選 mod，按「安裝／更新勾選mod」。操作前請關閉遊戲或伺服器。
4. 安裝完成後，依各 mod 提供的使用說明操作。

## 版本管理

- 可選擇本機已有的不同版本；「（推薦）最新版」依掃描到的數字版本判斷，同版本優先使用工作坊來源。
- 「版本管理」分頁可查看來源位置、選用版本、開啟來源資料夾及移除 ZIP 匯入來源。
- 移除匯入來源不會解除安裝 mod，檔案會備份到 `%LocalAppData%\UnturnedModManager\RemovedImports`。
- 切換較舊版本會先確認，仍保留檔案驗證、備份及復原流程。
- 管理器只列出本機已有的版本，不會下載工作坊歷史版本。

## 管理器更新

從 v1.0.1 起，每次開啟時會檢查本專案的 GitHub 正式版，有新版便提醒。網路失敗時仍可使用本機管理功能。

v1.0 使用者需先自行下載新版。Steam 更新的是工作坊來源檔案；已安裝到遊戲或伺服器的 mod，仍需在管理器重新掃描並執行更新。

## 使用條件

Windows 10／11、.NET Framework 4.8。管理器不附 mod 資源，需使用含相容安裝清單的安裝包。伺服器目標只接受宣告伺服器角色的模組。

ZIP 內附完整玩家使用說明。安裝異常時，請提供管理器操作紀錄中的完整提示。

## 支援內容與備份

支援附有有效 `unturned-manager.json` 的 mod 安裝包，以及含相容 `Data/version.json` 與 `Data/manifest.json` 的漢化安裝包。其他作者使用相容格式的 mod 也可匯入。

安裝前驗證檔案，保存備份與安裝紀錄。資料位於 `%LOCALAPPDATA%\UnturnedModManager`，請保留以便還原。已安裝檔案遭其他程式修改時，更新或移除會停止並提示衝突。

管理器不會執行安裝包中的 EXE 或腳本。伺服器功能操作本機可存取的 Windows 檔案，不提供遠端上傳或啟停控制。各 mod 的遊戲模式與相容性，請依作者說明確認。
