# Unturned 模組管理器 v1.0

本工具使用 OpenAI GPT 協助開發與撰寫說明。

Windows 桌面工具。玩家手動開啟，勾選漢化或模組後安裝，不必自己搬檔案。此工具不會啟動遊戲、修改 BattlEye 設定，或執行安裝包內的 EXE／腳本。

## 操作指南與回應速度優化版（待審查）

沿用 WinForms / .NET Framework 4.8，提供午夜紫、石墨黑、冰霧藍及奶油白。右上角可切換主題與三語，設定自動保存。

- 「使用指南」提供六個簡單步驟與實際入口，說明目標、Steam 下載、ZIP 匯入、掃描、安裝、更新及問題處理。
- 放大文字、提高對比、統一卡片分區；主要下拉選單及捲動條套用目前主題。Ctrl+F 搜尋、F5 掃描、Ctrl+A 勾選清單結果；版本可用 F4／Alt+↓ 選擇。
- 搜尋與批次選取一次更新，背景進度合併顯示；匯入或封存後只更新受影響項目，不重掃整個工作坊。
- 更新會驗證所有來源與已管理檔案，只寫入有變更或缺失的內容。保留手動修改保護、原始備份與交易回滾。
- ZIP 使用獨立暫存並可安全取消，完成後才加入來源；不自動刪除未完成內容或使用者模組。掃描也可取消。
- 作者提供 `unturned-manager.metadata.json` 時，模組名稱會跟隨介面語言；作者原文說明、版本名稱與未提供翻譯的名稱保留並標示，不修改版本或安裝身分。

請保留 EXE 與同名 `.exe.config`。本機量測的 120 模組全選後搜尋由 1,556 ms 降至 60 ms；512 檔相同內容更新由 4,114 ms 降至 661 ms。首次安裝與實際磁碟寫入沒有速度保證，完整數據、422 項檢查及限制見 [GUIDE-PERFORMANCE-驗證報告.md](GUIDE-PERFORMANCE-驗證報告.md)。

名稱交換格式見 [MOD-METADATA-v1.md](docs/MOD-METADATA-v1.md)，先前改版報告保留在 [DASHBOARD-驗證報告.md](DASHBOARD-驗證報告.md)。

### California 2 與其他 Data 分包

可直接匯入現有 California 2 v1.2 ZIP，或掃描其工作坊下載內容，不需要先執行獨立的漢化安裝器。管理器讀取既有 `Data/version.json`、`manifest.json`、`profiles.json`，辨識 `package_id` 並將 `Workshop/<ID>/.../Tchinese.dat` 分成獨立安裝範圍。

California 2 包中的地圖 `3707778928` 與資源 `3711646503` 可以分別勾選或批次安裝。先下載本體漢化、原始地圖與原始資源；每位玩家都需安裝，伺服器不會自動配送。管理器驗證原文及附加依賴，不執行 ZIP 裡的安裝器或腳本。

若先前使用獨立漢化安裝器，建議先用原工具還原。管理器不自動接管其備份；覆蓋時備份的是當下內容。Steam 更新工作坊原始檔案後，可能需重新安裝對應新版漢化。啟動選項 `-Lang=Tchinese` 仍由玩家手動設定。

## 玩家使用

1. 完整解壓縮管理器 ZIP。管理器不附另一份模組資源；使用你已下載的手動安裝包。
2. 開啟 `Unturned模組管理器.exe`。Windows 需有 .NET Framework 4.8（Windows 10／11 通常已有）；EXE 尚未數位簽章。
3. 確認遊戲資料夾內有 `Unturned.exe`。自動找到的位置不對時，按「瀏覽」。
4. 管理器會掃描工作坊內容；確認下載完成後，按「重新掃描」更新 mod 清單。
5. 勾選mod，按「安裝／更新勾選項目」。安裝前先關閉遊戲與伺服器。
6. 在同一遊戲位置勾選已安裝項目，可「解除安裝」，還原安裝前的檔案。

## 安裝到 Unturned 伺服器

1. 在「安裝目標」選擇「Unturned 伺服器」。
2. 按「自動尋找伺服器資料夾」，或在「伺服器資料夾」旁按「瀏覽」。選擇含 `Unturned.exe`／`Unturned_Headless.exe` 的伺服器根目錄。
3. 「mod來源資料夾」可以使用原本工作坊的位置，也可以按「瀏覽」選擇已解壓縮的同一份手動安裝包。
4. 先關閉伺服器，勾選適用的 mod，再按「安裝／更新勾選項目」。完成後重新啟動伺服器。

伺服器模式只接受 `.module` 內宣告 `Server`、`Both_Optional` 或 `Both_Required`，且管理器檔案清單包含對應 DLL 的模組。漢化及只有玩家端角色的模組會標示「不適用於伺服器」，不能安裝。這是檢查作者宣告，不代表已在實際伺服器驗證所有模組的相容性。

遊戲與伺服器的選擇位置分別記住；安裝紀錄與備份依實際目錄分開管理。同一實際目錄仍共用一份紀錄，避免重複管理同一批檔案。模組會放入所選根目錄的 `Modules`，不是特定存檔的資料夾；同一伺服器安裝目錄下的各實例可能共用這些模組。

自動尋找會讀取 Steam 專用伺服器的安裝清單。SteamCMD、自訂路徑或遠端主機位置請手動選擇；此版本操作本機可存取的 Windows 伺服器檔案，不提供遠端上傳、伺服器建立或啟停控制。

例如安裝物品整理工具 mod：先下載並解壓縮原本手動包，在「mod來源資料夾」選擇該包，再切換伺服器目標、指定伺服器根目錄並安裝。同一份包直接使用，不需要另製作伺服器資源包。

管理器會讀取 Steam 的遊戲庫設定，並掃描各遊戲庫的 `steamapps/workshop/content/304930`。支援現有漢化包原本的 `Data/version.json` 與 `Data/manifest.json`，以及未來附 `unturned-manager.json` 的手動安裝包。不會猜測其他作者模組的安裝方式。不相關的項目會略過。掃描到不代表現在帳號仍訂閱該項目：此版判斷的是本機已有檔案。

「自動尋找遊戲資料夾」會從 Steam 遊戲庫尋找含 Unturned.exe 的位置，以及工作坊資料夾；完成視窗會顯示是否找到遊戲、目前使用的完整路徑，再列出接著掃描 mod 的結果。「重新掃描」則使用目前位置更新 mod 清單，完成視窗顯示支援 mod 與已安裝的數量。

處理時，狀態列會顯示目前位置，進度列顯示動畫，操作按鈕暫時停用。找不到 mod 時也會說明如何檢查。遇到問題會顯示可捲動的視窗，列出原因、路徑及處理建議，完整訊息保留在「操作紀錄」。掃描本身不會驗證每個資源檔的 SHA-256，完整檔案驗證在安裝前執行。

會提示的情況包括遊戲位置無效、工作坊資料夾不存在或無法存取、mod 識別檔無效、安裝紀錄讀取失敗、操作中斷待復原，以及檔案權限、占用、磁碟空間不足等讀寫錯誤。自動尋找找到多個遊戲時，優先保留目前有效位置並提醒確認。啟動時也會自動掃描，若有問題會顯示提醒。

可以按「匯入 ZIP」選擇手動安裝包。匯入會解壓縮並加入 mod 清單，之後再勾選安裝；不會在匯入時直接寫入遊戲或伺服器。ZIP 必須包含一個有效安裝資料夾（可提供多個獨立漢化範圍），附有 `unturned-manager.json` 或支援的漢化 Data 清單；其他作者的相容安裝包也可使用，一般 DLL、地圖或物品 ZIP 不會猜測安裝位置。先前已匯入的 mod 與已記住的本機位置會持續讀取。清單同一識別碼出現多版時，顯示最高版本。

滑鼠停留在按鈕上約 0.6 秒，會顯示簡短操作說明。下方詳細資訊區顯示來源、目前安裝與選取版本、目標及來源路徑，以及作者提供的說明與玩家端／伺服器使用指引。作者內容保持原文。

## 使用既有漢化包

不製作「管理器專用漢化包」，不重複發布翻譯資料。管理器直接辨識「Unturned AI 繁中漢化」原有安裝包（含 Data、version.json 與 manifest.json）。可選含 Data 的資料夾，或直接選 Data。包內舊安裝器 EXE 不會被執行。安裝後，在 Steam 的 Unturned 啟動選項加入 `-Lang=Tchinese`。管理器不會自動更動 Steam 設定；解除漢化後自行移除這個選項。

若使用過原漢化安裝助手更新，遇到「目前檔案與管理器安裝紀錄不同」時，先選取對應版本，按上方「核對／接續紀錄」。管理器會核對目前檔案、來源清單、原助手紀錄及每份備份；這類差異不能直接判定為其他 Mod 或遊戲更新。核對有任何不符會停止，不提供強制忽略。

核對通過後會列出檔案數、備份數、兩工具不同的還原點及額外舊範圍。確認後採用原助手的還原點，將備份複製到新的獨立位置並更新管理器紀錄；原備份與原助手資料保留，管理器舊紀錄另存於 `ReconcileHistory`。接續本身不寫入、刪除或還原遊戲檔案。額外舊範圍保留為獨立項目，問題中心會持續提醒，未知修改不會自動處理。目前僅接受與原助手產品、目標、版本、範圍及完整清單一致的漢化；無有效紀錄或備份時須先查明原因。

接續後請使用此版或更新管理器進行還原，並完整保留 `ImportedOriginals` 與 `ReconcileHistory`。舊版管理器不認得獨立備份引用。不要直接刪除衝突檔案、清空安裝紀錄或備份。

## 備份與復原

設定、匯入包、安裝紀錄與備份放在 `%LOCALAPPDATA%\UnturnedModManager`，依遊戲位置分開記錄。請保留此資料夾，否則無法完整還原。移動管理器 EXE 不影響備份；移動遊戲目錄則不會自動搬移紀錄。

每個mod單獨進行交易：先驗證 SHA-256，備份，寫入並驗證，最後存紀錄。失敗時回復該mod；多個mod一起安裝時，前面成功的mod會保留。若程式遭中止，重新開啟後按「復原未完成的操作」，或在下一次安裝／移除前自動復原。復原應儘快進行，避免未完成狀態下又修改遊戲檔案。

已安裝檔案若被其他工具修改，更新／解除安裝會停止，保留修改內容。不同mod不可管理同一個目標檔案。初次安裝遇到不同檔案時，顯示詢問，允許後先備份再覆蓋。舊備份及交易快照暫時保留，以免誤刪。

## 發布與安裝

管理器與手動安裝包分開發布。每個 mod 只提供一份手動安裝包；玩家下載後，由管理器讀取工作坊內容，不需要輸入線上清單。

## 作者建立mod

把將安裝的檔案依遊戲相對位置放入 `payload`，例如 `payload/Modules/InventorySort/InventorySort.dll`。識別檔放在mod根目錄，與 payload 同層。

```json
{
  "schemaVersion": 1,
  "id": "yourname.inventory-sort",
  "name": "背包整理",
  "version": "1.0.0",
  "kind": "module",
  "description": "請描述模組用途與適用遊戲模式。",
  "afterInstall": "請依模組說明啟動遊戲。",
  "files": [
    {
      "source": "payload/Modules/InventorySort/InventorySort.dll",
      "target": "Modules/InventorySort/InventorySort.dll",
      "sha256": "這裡填該檔案的 64 字元 SHA-256"
    }
  ]
}
```

`id` 用小寫英數、句點、連字號，發布更新需保持相同。`version` 用數字版本。`kind=module` 只允許寫入自訂 `Modules/<模組名稱>/...`，保護 Framework、Unturned、Rocket.Unturned 官方模組位置。`kind=localization` 預設只接受 `Localization/Tchinese/**/*.dat`，以及 `Maps`／`Bundles` 裡的 `Tchinese.dat`。既有 Data 分包的 `Workshop/<ID>` 清單會轉為獨立工作坊語言範圍；原生清單亦可明確指定選用的 `scopeId`，僅限玩家端 localization 及 Tchinese.dat，必須有已下載的原始項目。不支援原版 DLL 替換、任意安裝腳本或服主外掛框架的專用安裝位置。

使用專案內的 `make-package.ps1` 可從 payload 自動產生識別檔、ZIP 與 SHA-256。同一個 ZIP 可以手動安裝（複製 payload 裡的內容），工作坊中同一份檔案也可由管理器掃描安裝。

工作坊只是可掃描來源之一。這份格式不代表 Unturned 工作坊已允許發布程式模組，發布許可仍需作者自行確認。

## 建置與驗證

在專案資料夾執行 `powershell -File build.ps1 -Test`。以 Windows 內建 .NET Framework C# 編譯器建置，不需 NuGet。測試只在 `TestResults` 建立假的遊戲檔案，不修改真正的 Unturned。`-Test` 同時執行核心安全、範圍與快取測試，以及三語介面整合測試，並產生各語言、各分頁、不同大小及縮放的 PNG 檢視檔。

管理器本身不包含 mod 資源，請另外下載要安裝的相容 mod 安裝包。



## 勾選及縮小視窗

模組與版本核取方塊支援單項點擊及空白鍵；群組支援全部／部分選取。模組頁底部按鈕會常駐，未符合操作條件時停用，窄視窗自動換行。導覽列收合後仍保留較大的點擊區及提示，進度條使用視窗全寬。
